# 冒险上下六千年

**选一个时代或画风，让你的角色骑着自行车穿越进去。**

在古埃及壁画里骑车，在撒哈拉岩画中穿行，或者进入一幅莫卧儿细密画……告诉 AI 你想去哪里，再选一个人物，它就会生成背景和骑行角色，做成一个会动的网页。

你不需要自己写代码、画图或制作动画。完成后，用浏览器打开网页就能看，也可以把文件发给朋友。

## 它能做什么？

- **换时代、换画风**：可以指定历史背景，也可以指定一种绘画风格。
- **用你喜欢的角色**：上传人物参考图，或使用内置的圆眼镜女生。
- **让人物融入画面**：保留角色的辨识特征，让线条、配色和服饰与场景协调。
- **做成骑行小动画**：人物循环踩踏，车轮转动，并从画面一侧骑向另一侧。
- **保存到自己的电脑**：得到一个可以离线打开的网页，以及可以单独使用的背景和人物图片。

## 使用前，需要准备什么？

这是一个给 AI 智能体使用的 **Skill（技能包）**。可以把它理解为一份带着工具和素材的操作指南，教 AI 按步骤完成这件事。

使用它的智能体需要能读取技能包、生成图片、读写本地文件，并运行 Python 脚本。比如，在具备这些能力的 Codex 环境中使用。**能安装 Skill，还需要能调用图片生成工具，才能完成整套作品。**

本 Skill 使用内置的 `image_gen` 图片生成工具，不需要你另外填写 API Key。能否生图、可用次数和额度，以你所用产品及账号为准。

Python 和 Pillow（一个处理图片的工具）可以让智能体帮忙检查和安装，你不用先研究它们。

## 怎么安装？

### 方法一：把安装指令复制给智能体

把下面整段话复制到智能体的聊天框，然后发送。仓库地址已经填好，可以直接复制。

这是给智能体看的指令，不需要粘贴到电脑终端里。

```text
请帮我安装“冒险上下六千年”Skill，技能名称是 cycling-through-history。

仓库地址：https://github.com/woaicat/cycling-through-history

请下载仓库中的 cycling-through-history.zip 并解压，找到包含 SKILL.md 的 cycling-through-history 文件夹，将它和内部全部文件安装到当前智能体支持的技能目录。

请保留 assets、references、scripts、agents 等目录，并检查 Python 和 Pillow 是否可用，以及当前环境能否调用内置 image_gen 图片生成工具。

完成后告诉我安装结果、技能所在位置，以及怎样开始使用；如果缺少必要能力，请用通俗语言说明。
```

如果你使用 Codex，也可以直接请它使用内置的 `skill-installer` 从仓库安装。安装后若没有识别到新技能，可以重新打开 Codex 再试。[安装方式参考 OpenAI 官方文档](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)。

### 方法二：下载技能包，再让智能体安装

如果你已经下载了 Skill 的 ZIP 压缩包，把它提供给智能体，或者告诉它压缩包在电脑上的位置，再发送：

```text
请帮我把这个压缩包里的 cycling-through-history Skill 安装好，保留全部配套文件，并检查生成骑行场景需要的工具是否可用。
```

如果智能体无法读取压缩包，可以先在电脑上解压，再把解压后的文件夹位置告诉它。

## 怎么开始玩？

安装好后，直接告诉智能体你想要的时代、画风和人物就可以了。

### 第一次尝试：用内置人物

复制这句话试试：

```text
请使用 cycling-through-history Skill，做一个在古埃及壁画世界里骑自行车的动态网页。使用内置的圆眼镜女生，生成完成后帮我打开预览。
```

内置人物是一位长棕发、戴圆眼镜的女生，穿蓝色衬衫、深色菱格背心和深蓝色宽腿裤。服装可以随时代调整；如果想保留原服装，在请求里加上“请保留人物原来的服装”。

### 想换成自己的角色

上传一张人物参考图，或告诉智能体图片在电脑上的位置，再说：

```text
请使用 cycling-through-history Skill，以我提供的人物作为主角，做一个在撒哈拉岩画风格场景里骑自行车的动态网页。保留人物的发型和眼镜，让人物和背景的画风一致。
```

参考图主要用于确定“这个人是谁”，最终画风会配合你选择的场景。同一项目继续创作时，会沿用已经选好的人物。

### 只有一个模糊的想法也可以

```text
请使用 cycling-through-history Skill，我想去唐代骑自行车，用内置人物。请先用一句话介绍你准备采用的画风，再开始制作。
```

你也可以试试：“莫卧儿细密画中的骑行”“中国水墨山水中的骑行”。这些是创作方向示例，具体效果由本次生成决定。

## 制作过程中会发生什么？

1. **选场景和人物**：你给出时代或画风；如果没有指定人物，AI 会先询问你。
2. **生成图片**：先制作背景，再制作三张不同踩踏姿势的透明人物图。
3. **检查和组装**：对齐人物大小和车轮位置，把图片做成动态网页。
4. **打开预览**：检查骑行效果，并把完成的文件交给你。

这包含多次图片生成，需要一些等待时间。人物动作、车轮转动或画风不合适时，可能需要修正部分素材；如果长时间没有进展，AI 应说明已经完成的部分和遇到的阻碍。

**网页里已经装入了全部图片。** 把 `index.html` 单独发给朋友，对方保存后用浏览器打开，也可以离线观看，不用安装这个 Skill。

网页提供暂停／继续、速度调整和四张图片下载功能。如果设备开启了“减少动态效果”，页面可能默认暂停，点击播放即可。

## 常见问题

### 不会写代码，可以用吗？

可以。你主要负责描述想要的效果、选择人物和查看结果，脚本运行与网页制作交给智能体。

### 普通聊天窗口也能用吗？

需要看它具备哪些工具。只有文字聊天或只能生成单张图片的环境，无法独立完成这套流程。可以先把安装指令发过去，让它检查是否支持。

### 能导出视频或 GIF 吗？

当前直接交付的是动态网页和 PNG 图片。如果需要视频或 GIF，需要另外录制或转换。

### 自行车出现在古代，是不是不符合历史？

这里采用的是“骑车穿越”的创作设定，历史背景提供场景与画风灵感，适合做趣味创作。

### 已经有喜欢的背景图，可以直接用吗？

可以把背景提供给智能体，并明确说“请复用这张背景”。它会检查构图和尺寸是否适合；可能需要调整背景，让人物有合适的骑行通道。

### 做好的网页需要联网吗？

制作时需要使用图片生成工具；完成后的网页可以离线打开，不需要服务器，也不用部署网站。
